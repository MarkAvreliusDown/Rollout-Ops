# Доска запуска торговых точек (cf_board)

Локальный Django-сайт для управления запуском/реконструкцией/доп. работами
торговых точек: задачи с автоматическим расчётом сроков, журнал работ по
объекту, отчёты с фото, база знаний, генератор писем/графиков, расчёт
бюджета, калькулятор зарплаты, Telegram-бот для ведения журнала прямо из
чата. Работает у тебя на компьютере (Windows), никуда не деплоится и не
уходит в облако — все данные остаются локально.

Это шаблон/каркас проекта без реальных рабочих данных: боевая база и
файлы (фото, документы) намеренно не публикуются. В комплекте — фикстура
с одним демонстрационным магазином, чтобы сразу увидеть, как всё выглядит.

## Что нужно один раз поставить

### 1. Python

Скачай Python 3.11 или новее: https://www.python.org/downloads/
При установке на Windows **обязательно поставь галочку "Add python.exe to
PATH"** на первом экране установщика.

Проверка (командная строка):
```
python --version
```

### 2. Git (если ещё нет)

https://git-scm.com/download/win — нужен, чтобы скачать (`git clone`) и
при желании сохранять свою историю изменений.

## Установка

Открой командную строку внутри папки проекта.

**1. Создать виртуальное окружение:**
```
python -m venv venv
```

**2. Активировать его:**

Windows (cmd):
```
venv\Scripts\activate
```
Windows (PowerShell):
```
venv\Scripts\Activate.ps1
```
Если сработало — в начале строки появится `(venv)`.

**3. Поставить зависимости:**
```
pip install -r requirements.txt
```

**4. Настроить переменные окружения:**

Скопируй `.env.example` в `.env` (рядом с `manage.py`) и заполни то, что
нужно — все поля необязательны, сайт работает и с пустым `.env`.

**5. Создать базу данных:**
```
python manage.py migrate
```

**6. (Необязательно) Загрузить демо-данные** — один пример магазина с
задачами, контактом и заметкой, чтобы посмотреть, как выглядит доска:
```
python manage.py loaddata demo_data
```

**7. (Необязательно) Создать логин в админку** (`/admin/`):
```
python manage.py createsuperuser
```

**8. Запустить сайт:**
```
python manage.py runserver
```
Открой в браузере: **http://127.0.0.1:8000/**

Остановить сервер — `Ctrl+C` в терминале.

### Каждый следующий раз (после первой установки)

```
cd путь\до\папки\проекта
venv\Scripts\activate
python manage.py runserver
```

## Необязательные возможности

### ИИ-чат и ИИ-поиск по базе знаний

Работают через локальную модель Ollama — ничего не уходит в интернет. Без
Ollama сайт работает полностью, кроме этих двух функций.

1. Установи Ollama: https://ollama.com
2. Скачай модель (по умолчанию `qwen2.5:7b`, задаётся в `.env` через
   `OLLAMA_MODEL`):
   ```
   ollama pull qwen2.5:7b
   ```
3. Перед запуском сайта убедись, что приложение Ollama запущено (обычно
   стартует само после установки и висит в трее).

### Telegram-бот

Позволяет вести журнал объекта и заметки прямо из Telegram, без захода на
сайт.

1. Создай бота через [@BotFather](https://t.me/BotFather), получи токен.
2. Впиши токен в `.env` (`TELEGRAM_BOT_TOKEN`).
3. Напиши что-нибудь своему боту в Telegram, затем запусти
   `python get_telegram_chat_id.py`, чтобы узнать свой `chat_id`.
4. Впиши `chat_id` в `.env` (`TELEGRAM_CHAT_ID`, можно несколько через
   запятую).
5. Запусти бота отдельным окном/процессом:
   ```
   python manage.py telegram_bot
   ```
   Бот работает через long polling — не нужен белый IP или домен.

### Пароль на сайт

Если хочешь ограничить доступ (например, сайт доступен и с других
устройств в локальной сети) — задай `SITE_PASSWORD` в `.env`. Пусто =
сайт открыт без пароля.

### Доступ с других устройств в локальной сети

По умолчанию `python manage.py runserver` слушает только
`127.0.0.1`. Чтобы сайт был виден с телефона/другого компьютера в той же
Wi-Fi-сети:
```
python manage.py runserver 0.0.0.0:8000
```
Дальше с другого устройства — `http://<IP-компьютера>:8000` (свой IP
смотри через `ipconfig`). Обязательно задай `SITE_PASSWORD` перед этим —
без пароля сайт будет открыт всем в сети.

### Бэкапы

```
python manage.py backup
```
Собирает `db.sqlite3` и папку `media/` в один ZIP в `C:\mybacks\` (папка
создаётся сама). `.env` в архив не попадает.

### Локальные снимки в git (версионирование)

```
python manage.py git_snapshot
```
Делает коммит всего проекта (код + база + медиа) в **локальный** git-репозиторий —
удобно, чтобы можно было откатиться к любому дню. Не имеет отношения к
публикации на GitHub — это отдельный, полностью локальный репозиторий.
Требует, чтобы `git init` был один раз выполнен в папке проекта.

## Частые проблемы

- **"python не является внутренней командой"** — Python не в PATH,
  переустанови с галочкой "Add to PATH".
- **`pip install` долго висит / ошибка сети** — проверь интернет, попробуй
  ещё раз.
- **Порт 8000 занят** — `python manage.py runserver 8001`, открой
  `http://127.0.0.1:8001/`.
- **Фото не отображаются** — убедись, что папка `media/` создалась рядом
  с `manage.py` (создаётся автоматически при первой загрузке файла).
- **ИИ-чат/поиск выдаёт ошибку** — проверь, что приложение Ollama
  запущено.
- **Бот не отвечает** — проверь, что `TELEGRAM_BOT_TOKEN` верный и
  процесс `python manage.py telegram_bot` запущен и не упал с ошибкой в
  консоли.
